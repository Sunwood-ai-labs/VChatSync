# 同期スクロール・サイドチャット

これは、動画とチャットログを同期させるためのシンプルなWebアプリケーションです。

## ✨ 機能

- 動画の再生に合わせて、チャットログが自動でスクロールします。
- チャットのタイムスタンプをクリックすると、動画の再生位置がその時間に移動します。

## 🚀 使い方

1.  `index.html` をブラウザで開きます。
2.  動画ファイルとチャットログ（JSON形式）を選択します。
3.  動画を再生すると、チャットが同期して表示されます。
